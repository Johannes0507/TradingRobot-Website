## 安全提醒

**✅ 應該做：**
- 用密碼管理器保存 Key（不要存 Notes、Email、Slack）
- 開啟 IP 白名單
- 每 6 個月主動輪替一次 Key

**❌ 絕對不要：**
- 在 Bitfinex 開 Withdraw 權限（無法挽救）
- 把 Secret 截圖上傳雲端
- 跟任何「LendAuto 工程師」分享 Secret — 我們不會、也不需要問

## 常見問題

**Q：權限設錯可以改嗎？** 不行。Bitfinex 的 Key 建立後權限無法修改，只能砍掉重建。

**Q：Key 會過期嗎？** Bitfinex 的 Key 不會自動過期，但建議每 6 個月主動換一次。

**Q：可以同一個 Key 接到別的服務嗎？** 強烈建議不要。每個服務獨立 Key，出事時砍掉不影響其他。

**Q：驗證失敗怎麼辦？** 三個常見原因：(1) Funding 三項沒勾全；(2) IP 白名單擋到（先暫關測試）；(3) Secret 開頭結尾有空白字元。三個都查過還不行就[寄信給我們](mailto:hello@lendauto.com)，附 Key 前 4 碼（不要附 Secret）。
