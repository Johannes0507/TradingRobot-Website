# TradingRobot Website

Official marketing website for the Bitfinex Lending Robot — an automated crypto lending management platform.

## Project Structure

```
├── frontend/          # React component prototypes
│   ├── App.jsx
│   ├── Sections.jsx
│   ├── FluidRibbon.jsx   # WebGL aurora animation (nebula vortex)
│   ├── MeshGradient.jsx
│   ├── Dashboard.jsx
│   └── Icons.jsx
├── backend/           # Backend services (in progress)
└── docs/              # Design references and project documents
    ├── images/        # Reference screenshots & UI mockups
    ├── prompts/       # Project handover documents (gitignored)
    └── frontend-video/ # Animation reference videos (gitignored)
```

## Tech Stack

- **Frontend:** React, WebGL (custom GLSL shaders), Tailwind CSS
- **Animation:** Fluid ribbon / mesh gradient hero effects
- **Backend:** TBD
